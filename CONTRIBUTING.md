# Contributing to $repo

Thank you for your interest in contributing! This is a Manta open-source project.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/$repo.git`
3. Run tests: `python -m pytest`

## Pull Request Process

1. Ensure tests pass before submitting
2. Add tests for new functionality
3. Update the README if changing behavior
4. Keep changes focused — one feature per PR

## Code Style

- Follow PEP 8
- Use type hints where helpful
- Keep it simple — zero external dependencies is a feature

## Reporting Issues

Open an issue with:
- A clear description of the problem
- Steps to reproduce
- Expected vs actual behavior
- Python version and OS
